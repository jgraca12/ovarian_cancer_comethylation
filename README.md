# ovarian_cancer_comethylation
Code for the project developed in MSB1014 in the academic year 2026/2027.
This project investigated co-methylation patterns in TCGA ovarian cancer samples and their association with platinum resistence.

The analysis includes:
- DNA methylation data processing
- Weighted Gene Co-expression Network Analysis (WGCNA) applied to DNA methylation data
- Comparison of co-methylation patterns between platinum-sensitive and platinum-resistant samples
- GPR97 exploratory network visualization
- Gene Ontology (GO) enrichment analysis

Data was obtained from TCGA through cBioPortal
Tools: R, WGCNA, Cytoscape and clusterProfiler
